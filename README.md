# VisaMOTion365 — visamotion300

Faithful static export of the original visamotion300.lovable.app site with one change:
the colour theme is now Apple iOS 26 Liquid Glass (white surfaces, #007AFF blue,
#7A5CFA violet wash). Layout, sections, copy, spacing and type are identical.

- 67 pages, all internal links point at local pages
- Colour tokens live in `assets/glass-theme.css` only
- `assets/static-enhance.js` restores the header and mobile menu behaviour
